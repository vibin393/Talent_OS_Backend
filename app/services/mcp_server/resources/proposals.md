# Proposals and approvals

When a tool says it creates a proposal, nothing has happened yet.

1. The proposal appears in the user's Proposals inbox in Talent OS, titled "Requested by <assistant> for <user> through MCP".
2. The user reviews the details and approves or declines it. Sending checks run again at approval time.
3. Only an approved proposal is carried out, by Talent OS, under the user's own access.

A session can create at most 25 proposals per hour (the organisation may set a lower limit).
