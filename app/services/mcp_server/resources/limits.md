# Limits and data protection

- Tool calls per session per minute: set by the organisation's plan (30, 60 or 120) and possibly lowered by the organisation.
- Tool calls per person per day: up to 2,000; the count resets at 00:00 UTC.
- Proposals per session per hour: up to 25.
- Records per tool result: up to 50.
- A session that reads an unusual number of different candidate records in an hour is paused, and the person's
  assistant access waits for an AI Administrator.
- Identity numbers (Aadhaar, PAN, passport), bank details and, unless granted, contact details are always redacted.
- Every call is recorded in the organisation's AI governance console.
